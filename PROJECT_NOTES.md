# Project Notes

## Project Chosen

Astrologer CRM

## Tech Stack

* React
* Node.js
* Express.js
* MongoDB Atlas
* Mongoose
* Axios

## Architecture

The frontend is built using React and communicates with backend REST APIs using Axios.

The backend is developed using Node.js and Express.js.

MongoDB Atlas is used as the cloud database, and Mongoose is used for schema modeling and database operations.

## Assumptions

* Single admin dashboard
* No authentication implemented
* Appointments are managed through APIs
* Data is stored in MongoDB Atlas

## Future Improvements

* User Authentication
* Appointment Status Updates
* Search and Filtering
* Dashboard Analytics
* Responsive UI
